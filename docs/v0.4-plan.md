# SnapTok v0.4 implementation

Scope: all proposed download, library, floating-control and media-tool features; cohesive animated UI. Public content only; no login, DRM bypass or store submission.

1. Durable settings & schema migration: constraints, size limit, item index, audio mode, favourites, collections, source metadata.
2. FFmpeg merging; media inspection & multi-item selection; batch import; optional per-platform defaults; source identity deduplication & missing-file recovery.
3. Save / Library / Settings navigation; themes, reduced motion, list/grid, accessible controls; local player with speed/resume; trim & audio export as new files.
4. Storage accounting & safe cleanup/deletion; floating progress, count, results, fade, haptics, optional action menu & restore notification.
5. Platform beta support only with explicit validation boundaries. Tests, upgrade checks, on-device flows, APK verification.

Guardrails: preserve prior changes; never overwrite source media during editing; no broad storage/clipboard access; keep quality/destination/preferences with each queued request; distinguish unknown failures from success.
