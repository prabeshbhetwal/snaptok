# SnapTok v0.3

Scope: compact home; searchable library; Failed filter; local thumbnails and actual file details; share saved files; remove history without deleting media; source-specific recovery; public Instagram Reel/post beta.

Acceptance:
- Share receiver remains one-tap and background-capable.
- Canonical Instagram URLs deduplicate Reel/post aliases; reject profiles, Stories, spoofed hosts and credentials.
- Existing Room records and folder permissions survive update; no schema change required.
- Metadata and thumbnails read from saved content URIs on an IO dispatcher; no remote thumbnail request.
- Rate limits and access blocks receive clear messages without repeated automatic retries.
- History removal requires confirmation, applies only to terminal jobs and preserves files.
- Existing tests plus targeted parser, search, recovery, metadata and history tests pass.
- Check compact UI and perform live Instagram extraction on Android; report sample outcomes without claiming universal support.

Excluded: YouTube, Facebook, Reddit, accounts/cookies, Stories, playlists, FFmpeg, theme redesign, pause/resume, public store release.
